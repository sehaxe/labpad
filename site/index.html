Отчёт по лабе —
за пару минут

Условие, блок-схема из кода, код и результат — на одном листе А4. Схема приезжает из gostpadi, вёрстка собирается в Typst, PDF скачивается прямо из браузера.

Что попадает в отчёт

одна карточка = одно задание
  • [+]
    Условие — вставляешь текст из методички, он ложится на лист без правок.
  • [+]
    Блок-схема — генерится из кода тем же движком, что в gostpadi: ГОСТ 19.701-90, вектор.
  • [+]
    Код — с подсветкой C, переносами по ширине листа и нумерацией строк по желанию.
  • [+]
    Результат — скриншот консоли, вставляется перетаскиванием.
  • [+]
    PDF по ГОСТ — Typst в браузере (WASM), без сервера: компилятор грузится только по кнопке.

Как это работает

три шага, без установки
01

Вставь код

Код задания — в карточку. Схема перерисуется сама, если поправить код.

02

Собери лист

Титул, условие, схема, код и результат ложатся на А4 по ГОСТ.

03

Скачай PDF

Typst компилирует в браузере: вектор, шрифт, поля — как в типографии.

Почему Typst

а не Word

[+] Поля и шрифт по ГОСТ

Левое 20 мм, правое 10 мм, полуторный интервал, Times-совместимый шрифт. Один шаблон — все лабы семестра.

[+] Схемы — с запасом по разрешению

Блок-схема из gostpadi растеризуется в 2× и вставляется в PDF: на печати линии и текст остаются чёткими.

[+] Никакой возни с колонтитулами

Нумерация страниц, титульник и разрывы — в шаблоне. Ты правишь данные, а не оформление.

[+] Один шаблон для людей и агентов

Тот же .typ собирается в PDF из браузера и из CLI: результат идентичный.

Связка с gostpadi

один движок схем

labpad не рисует схемы сам: он просит их у gostpadi — того же движка, что на сайте и в CLI. Правка кода в карточке перерисовывает схему, не покидая редактор.

# из карточки задания
labpad build report.json -o report.pdf
# схема берётся из gostpadi, дальше — typst
