# labpad

Редактор отчётов по лабораторным работам: условие, блок-схема из кода, код и результат — на одном листе А4, экспорт PDF.

## Что внутри

- `site/index.html` — лендинг.
- `site/app.html` — редактор отчёта (каркас: титул + карточки заданий).
- Схемы — из [gostpadi](https://sehaxe.github.io/gostpadi/) (один движок).
- PDF — печать из браузера (`Ctrl+P`): стиль листа задаёт поля, шрифт и разрывы страниц; схемы остаются вектором.

## Стек

- Сайт: статический HTML/CSS/JS, без сборки и сервера.
- Запуск C: локальный runner на Rust (`runner/`, без зависимостей) либо облачный Judge0; вывод — как в терминале.
- Шрифт отчёта: Liberation Serif (метрически совместим с Times New Roman).

## Локальный запуск

```bash
python3 -m http.server 8099 --directory site
# http://127.0.0.1:8099/
```

## Локальный запуск C (вывод программы)

```bash
cd runner && cargo run --release        # http://127.0.0.1:8788
```

Редактор сам найдёт runner: блок «Вывод программы» получает режимы
«запустить» (компилирует cc/gcc и подставляет stdin) и «вставить вручную».

Если runner не запущен, вывод считается в публичном облаке Judge0
(https://ce.judge0.com, C/GCC) — работает и на статическом сайте без
установки. Код в этом случае уходит на сторонний сервис; локальный runner
быстрее (≈50 мс против ≈1–2 с) и приватнее.
